§§chapter js-variables
part: js
title: Variables, types et console
subtitle: let, const, nombres, chaînes, booléens, gabarits
duration: 1 h 30
feature: Numéro de commande et informations d'une commande
§intro
<p>Le <strong>JavaScript</strong> est le langage qui rend la page vivante : il calcule, réagit aux clics, enregistre les données. Il est exécuté par le navigateur.</p>
<p>Une <strong>variable</strong> est une boîte étiquetée qui contient une valeur. On la crée avec :</p>
<ul>
<li><code>const</code> : la boîte ne sera <strong>pas réaffectée</strong> (à utiliser par défaut) ;</li>
<li><code>let</code> : la valeur peut changer (un compteur, un total qui s'accumule).</li>
</ul>
<p>(On croise encore <code>var</code> dans de vieux codes : on ne l'utilise plus.)</p>
<p>Les <strong>types</strong> de base : <code>number</code> (12, 8.5), <code>string</code> (texte entre guillemets), <code>boolean</code> (<code>true</code>/<code>false</code>), <code>null</code> (vide volontaire), <code>undefined</code> (pas encore de valeur). Les <strong>gabarits</strong> (template literals), entre accents graves <code>`…`</code>, insèrent une variable avec <code>${variable}</code>.</p>
<p>Pour voir ce qui se passe, on affiche dans la <strong>console</strong> (F12 → Console) avec <code>console.log()</code>.</p>
§example js
// const : valeur fixe (on ne réaffecte pas la variable)
const prefixe = 'CMD';
const annee = 2026;

// let : valeur qui va changer
let compteur = 41;
compteur = compteur + 1;          // ou compteur++ → 42

// Un numéro de commande formaté : CMD-2026-0042
// padStart(4, '0') complète à gauche avec des zéros
const numero = `${prefixe}-${annee}-${String(compteur).padStart(4, '0')}`;
console.log(numero);              // CMD-2026-0042

// Les types
const client = 'Brico Sud';       // string
const quantite = 10;              // number
const urgente = false;            // boolean
let dateLivraison = null;         // pas encore planifiée
console.log(typeof client, typeof quantite, typeof urgente); // string number boolean

// Attention aux décimales : on calcule l'argent en CENTIMES entiers
console.log(0.1 + 0.2);           // 0.30000000000000004 !
const prixCentimes = 850;         // 8,50 €
console.log(prixCentimes * quantite / 100); // 85
§explain
<ul>
<li>Chaque instruction se termine par un point-virgule <code>;</code> (recommandé).</li>
<li><code>//</code> commente une ligne, <code>/* … */</code> plusieurs lignes.</li>
<li>Noms de variables en <strong>camelCase</strong> : <code>dateLivraison</code>, explicites et en français ou en anglais, mais pas un mélange.</li>
<li><code>String(compteur)</code> convertit le nombre en texte pour pouvoir utiliser <code>padStart</code>.</li>
<li>Les ordinateurs stockent les décimales en binaire, d'où <code>0.1 + 0.2 ≠ 0.3</code>. Ondea stocke donc tous les montants en <strong>centimes entiers</strong>.</li>
<li><code>typeof</code> renvoie le type d'une valeur, utile pour déboguer.</li>
</ul>

§§chapter js-conditions
part: js
title: Conditions
subtitle: if / else, opérateurs de comparaison et logiques, switch, ternaire
duration: 1 h 30
feature: Alertes de stock et droits des profils
§intro
<p>Une <strong>condition</strong> permet au programme de prendre une décision : <em>si</em> le stock est sous le seuil, <em>alors</em> afficher une alerte, <em>sinon</em> rien.</p>
<ul>
<li>Comparaisons : <code>===</code> (strictement égal), <code>!==</code> (différent), <code>&lt;</code>, <code>&gt;</code>, <code>&lt;=</code>, <code>&gt;=</code>. Toujours <code>===</code> et jamais <code>==</code> qui convertit les types de façon surprenante.</li>
<li>Logique : <code>&amp;&amp;</code> (ET), <code>||</code> (OU), <code>!</code> (NON).</li>
<li><code>if (…) { } else if (…) { } else { }</code> : plusieurs cas.</li>
<li><code>switch</code> : quand on compare une même valeur à une liste de cas.</li>
<li>Le <strong>ternaire</strong> <code>condition ? siVrai : siFaux</code> : un if/else court qui renvoie une valeur.</li>
</ul>
<p>Valeurs « fausses » (falsy) : <code>false</code>, <code>0</code>, <code>''</code>, <code>null</code>, <code>undefined</code>, <code>NaN</code>. Toutes les autres sont « vraies ».</p>
§example js
const stock = 4;
const seuilAlerte = 5;

// if / else if / else : du cas le plus grave au moins grave
if (stock === 0) {
  console.log('Rupture de stock');
} else if (stock <= seuilAlerte) {
  console.log('Stock faible : réapprovisionner');
} else {
  console.log('Stock suffisant');
}

// Opérateurs logiques : && (ET), || (OU)
const role = 'magasinier';
const commandeValidee = true;
if (role === 'directeur' || (role === 'magasinier' && commandeValidee)) {
  console.log('Peut lancer la préparation');
}

// switch : libellé à partir d'une clé de statut
const statut = 'expediee';
let libelle;
switch (statut) {
  case 'validee':  libelle = 'Validée'; break;
  case 'expediee': libelle = 'Expédiée'; break;
  case 'livree':   libelle = 'Livrée'; break;
  default:         libelle = 'Inconnu';
}
console.log(libelle);

// Ternaire : une valeur selon une condition
const badge = stock <= seuilAlerte ? 'badge-danger' : 'badge-success';
console.log(badge);
§explain
<ul>
<li>L'ordre des <code>else if</code> compte : le premier test vrai gagne, les suivants sont ignorés. On teste donc <code>stock === 0</code> avant <code>stock &lt;= 5</code>.</li>
<li>Les parenthèses clarifient les priorités : <code>&amp;&amp;</code> passe avant <code>||</code>.</li>
<li>Dans un <code>switch</code>, <code>break</code> arrête l'exécution ; sans lui, on « tombe » dans le cas suivant.</li>
<li><code>'5' == 5</code> vaut <code>true</code> mais <code>'5' === 5</code> vaut <code>false</code> : <code>===</code> compare aussi le type.</li>
<li>Le ternaire est parfait pour choisir une classe CSS ou un texte ; pour plusieurs instructions, préférez un if.</li>
</ul>

function autoriser(role, action) {
  if (role === 'directeur') return true;
  switch (action) {
    case 'preparer':
    case 'expedier':
      return role === 'magasinier';
    default:
      return false;
  }
}
// Version « matrice »
const DROITS = { magasinier: ['preparer', 'expedier'] };
function autoriser2(role, action) {
  return role === 'directeur' || (DROITS[role] || []).includes(action);
}
for (const role of ['directeur', 'magasinier']) {
  for (const action of ['voir-finances', 'preparer', 'supprimer-commande', 'expedier']) {
    console.log(role, action, autoriser2(role, action) ? 'Autorisé' : 'Refusé');
  }
}

§§chapter js-boucles
part: js
title: Boucles
subtitle: for, for…of, while et accumulation
duration: 1 h
feature: Total des lignes d'une commande
§intro
<p>Une <strong>boucle</strong> répète des instructions. C'est indispensable dès qu'on a une liste : additionner toutes les lignes d'une commande, afficher tous les clients, compter les commandes en retard.</p>
<ul>
<li><code>for (let i = 0; i &lt; n; i++)</code> : la boucle classique avec un compteur.</li>
<li><code>for (const element of tableau)</code> : parcourt chaque élément d'un tableau. <strong>La plus lisible</strong>, à préférer.</li>
<li><code>while (condition)</code> : répète tant que la condition est vraie (attention à la boucle infinie !).</li>
<li><code>break</code> sort de la boucle ; <code>continue</code> passe directement au tour suivant.</li>
</ul>
<p>Le schéma le plus courant est l'<strong>accumulateur</strong> : une variable <code>let total = 0</code> avant la boucle, à laquelle on ajoute une valeur à chaque tour.</p>
§example js
// Quantités et prix (en centimes) des lignes d'une commande
const quantites = [10, 2, 5];
const prix      = [850, 12900, 400];

// 1. for classique : i va de 0 à 2
let totalHT = 0;                       // accumulateur
for (let i = 0; i < quantites.length; i++) {
  totalHT += quantites[i] * prix[i];   // += : ajoute à la valeur actuelle
}
console.log(totalHT);                  // 36300 centimes = 363,00 €

// 2. for...of : parcourt directement les valeurs
const statuts = ['livree', 'attente', 'livree', 'annulee', 'livree'];
let nbLivrees = 0;
for (const s of statuts) {
  if (s === 'annulee') continue;       // on ignore les annulées
  if (s === 'livree') nbLivrees++;
}
console.log(`${nbLivrees} commandes livrées`);

// 3. while : réapprovisionner par cartons de 12 jusqu'au seuil
let stock = 3;
let cartons = 0;
while (stock < 30) {
  stock += 12;
  cartons++;
}
console.log(`${cartons} cartons → stock ${stock}`); // 3 cartons → stock 39
§explain
<ul>
<li>Les indices d'un tableau commencent à <strong>0</strong> : le dernier est à <code>length - 1</code>, d'où <code>i &lt; length</code> (et non <code>&lt;=</code>).</li>
<li><code>i++</code> ajoute 1 à <code>i</code> après chaque tour.</li>
<li><code>totalHT += x</code> est le raccourci de <code>totalHT = totalHT + x</code>.</li>
<li>Avec <code>for…of</code>, pas d'indice à gérer : moins de risque d'erreur.</li>
<li>Dans un <code>while</code>, quelque chose doit faire évoluer la condition (ici <code>stock += 12</code>), sinon la page se fige.</li>
</ul>

  { nom: 'Vis inox 4x40', stock: 12, seuil: 50 }, { nom: 'Perceuse 18 V', stock: 2, seuil: 5 },
  { nom: 'Chevilles 8 mm', stock: 0, seuil: 100 }, { nom: 'Équerre 60 mm', stock: 80, seuil: 20 },

§intro
<p>Une <strong>fonction</strong> est une recette réutilisable : on lui donne des ingrédients (les <strong>paramètres</strong>), elle fait un travail et renvoie un résultat avec <code>return</code>.</p>
<p>Avantages : on écrit le calcul de la TVA <strong>une seule fois</strong> et on l'utilise partout ; si la règle change, on ne corrige qu'à un endroit. On peut aussi tester la fonction seule.</p>
<ul>
<li>Déclaration : <code>function calculerTVA(ht, taux) { return … }</code></li>
<li>Fonction fléchée : <code>const calculerTVA = (ht, taux) =&gt; …</code> (plus courte, très utilisée avec les tableaux).</li>
<li>Paramètre par défaut : <code>function f(taux = 20)</code>.</li>
<li><strong>Portée</strong> : une variable créée dans une fonction n'existe que dans cette fonction.</li>
</ul>
<p>Une bonne fonction fait <strong>une seule chose</strong>, porte un nom qui commence par un verbe (<code>calculer</code>, <code>formater</code>, <code>valider</code>) et ne modifie pas les données qu'on lui donne.</p>
§example js
/**
 * Calcule la TVA d'un montant HT.
 * @param {number} htCentimes  montant hors taxes en centimes
 * @param {number} tauxPourcent taux de TVA (20, 10, 5.5)
 * @returns {number} TVA en centimes, arrondie au centime
 */
function calculerTVA(htCentimes, tauxPourcent = 20) {
  return Math.round(htCentimes * tauxPourcent / 100);
}

// Fonction fléchée : une ligne, return implicite
const calculerTTC = (htCentimes, taux = 20) => htCentimes + calculerTVA(htCentimes, taux);

// Formater des centimes en euros à la française
const formaterEuros = (centimes) =>
  new Intl.NumberFormat('fr-FR', { style: 'currency', currency: 'EUR' }).format(centimes / 100);

// Une fonction qui en utilise d'autres
function resumeLigne(designation, quantite, puCentimes, taux) {
  const ht = quantite * puCentimes;
  return `${designation} : ${formaterEuros(ht)} HT, ${formaterEuros(calculerTTC(ht, taux))} TTC`;
}

console.log(calculerTVA(10000));                     // 2000 (20 € sur 100 €)
console.log(calculerTTC(2000, 5.5));                 // 2110
console.log(resumeLigne('Perceuse 18 V', 2, 12900, 20));
// Perceuse 18 V : 258,00 € HT, 309,60 € TTC
§explain
<ul>
<li>Le commentaire <code>/** … */</code> (JSDoc) documente les paramètres : l'éditeur l'affiche en info-bulle.</li>
<li><code>return</code> renvoie la valeur <strong>et arrête</strong> la fonction. Sans <code>return</code>, la fonction renvoie <code>undefined</code>.</li>
<li><code>tauxPourcent = 20</code> : si on n'envoie pas de taux, 20 est utilisé.</li>
<li>Une fléchée sans accolades renvoie directement son expression. Avec accolades, il faut écrire <code>return</code>.</li>
<li><code>Math.round()</code> arrondit à l'entier le plus proche : indispensable pour garder des centimes entiers.</li>
<li>On appelle une fonction avec des parenthèses : <code>calculerTVA(10000)</code>. Sans parenthèses, on manipule la fonction elle-même sans l'exécuter.</li>
</ul>

/** « 1 234,56 » → 123456 centimes (NaN si invalide) */
function versCentimes(saisie) {
  const s = String(saisie).replace(/\s/g, '').replace(',', '.');
  if (!/^\d+(\.\d{1,2})?$/.test(s)) return NaN;
  const [ent, dec = ''] = s.split('.');
  return Number(ent) * 100 + Number((dec + '00').slice(0, 2));
}
/** 123456 → « 1 234,56 € » */
const formaterEuros = (c) => new Intl.NumberFormat('fr-FR', { style: 'currency', currency: 'EUR' }).format(c / 100);

/** Totaux d'une commande. lignes : [{ qte, pu, remise, taux }] en centimes / % */
function totalCommande(lignes, fraisPortHT = 0, tauxPort = 20) {
  const parTaux = {};
  let totalHT = 0;
  const ajouter = (ht, taux) => {
    const tva = Math.round(ht * taux / 100);
    parTaux[taux] = parTaux[taux] || { base: 0, tva: 0 };
    parTaux[taux].base += ht; parTaux[taux].tva += tva;
    totalHT += ht;
    return tva;
  };
  let totalTVA = 0;
  for (const l of lignes) {
    const ht = Math.round(l.qte * l.pu * (100 - l.remise) / 100);
    totalTVA += ajouter(ht, l.taux);
  }
  if (fraisPortHT) totalTVA += ajouter(fraisPortHT, tauxPort);
  return { totalHT, parTaux, totalTVA, totalTTC: totalHT + totalTVA };
}
const r = totalCommande([
  { qte: 10, pu: 850, remise: 0, taux: 20 }, { qte: 2, pu: 12900, remise: 10, taux: 20 },
  { qte: 5, pu: 400, remise: 0, taux: 20 }, { qte: 1, pu: 2000, remise: 0, taux: 5.5 },
  { qte: 4, pu: 250, remise: 0, taux: 20 }
], 1000);
console.log(formaterEuros(r.totalTTC)); // 449,74 €

§intro
<p>Un <strong>objet</strong> regroupe les informations d'une même chose sous forme de paires <code>clé: valeur</code> : un client a un nom, un e-mail, une ville. Un <strong>tableau</strong> est une liste ordonnée : la liste des clients.</p>
<p>Ensemble, ils modélisent toutes les données d'Ondea : un tableau de commandes, chaque commande est un objet qui contient un tableau de lignes, chaque ligne est un objet.</p>
<p>Les méthodes de tableau à connaître absolument (elles ne modifient pas le tableau d'origine) :</p>
<ul>
<li><code>filter(fn)</code> : garde les éléments qui passent le test → les commandes en attente.</li>
<li><code>map(fn)</code> : transforme chaque élément → la liste des noms.</li>
<li><code>find(fn)</code> : le premier élément qui correspond → le client n° 3.</li>
<li><code>reduce(fn, départ)</code> : combine tout en une valeur → le chiffre d'affaires.</li>
<li><code>some</code>/<code>every</code>, <code>includes</code>, <code>sort</code>, <code>push</code>.</li>
</ul>

§intro
<p>Un <strong>événement</strong> est quelque chose qui se produit : un clic, une touche pressée, un champ modifié, la page chargée, l'adresse qui change. On demande au navigateur : « quand <em>cet événement</em> arrive sur <em>cet élément</em>, exécute <em>cette fonction</em> ».</p>
<p><code>element.addEventListener('click', maFonction)</code></p>
<p>Événements courants : <code>click</code>, <code>input</code> (à chaque frappe), <code>change</code> (valeur validée), <code>submit</code> (formulaire), <code>keydown</code> (touche), <code>hashchange</code> (adresse #), <code>DOMContentLoaded</code> (HTML prêt).</p>
<p>La fonction reçoit un objet <code>event</code> : <code>event.target</code> (l'élément cliqué), <code>event.key</code> (la touche), <code>event.preventDefault()</code> (annule le comportement par défaut).</p>

<li>Valider et construire un objet <code>erreurs</code>.</li>
<li>S'il y a des erreurs : les afficher, marquer les champs <code>aria-invalid="true"</code>, mettre le focus sur le premier champ en erreur.</li>
<li>Sinon : enregistrer, afficher un message de succès, réinitialiser.</li>
</ol>
<p>Attention : <code>input.value</code> est <strong>toujours une chaîne</strong>. Pour calculer : <code>Number(...)</code>.</p>
§example js
const form = document.querySelector('#form-client');

form.addEventListener('submit', (event) => {
  event.preventDefault();                       // pas de rechargement

  // 1. Lire toutes les valeurs d'un coup (clé = attribut name)
  const donnees = Object.fromEntries(new FormData(form));
  donnees.nom = donnees.nom.trim();

  // 2. Valider : un objet { nomDuChamp: 'message' }
  const erreurs = {};
  if (donnees.nom.length < 2) erreurs.nom = 'La raison sociale doit contenir au moins 2 caractères.';
  if (donnees.email && !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(donnees.email)) {
    erreurs.email = "L'adresse e-mail n'est pas valide (exemple : contact@societe.fr).";
  }
  if (!/^\d{5}$/.test(donnees.cp)) erreurs.cp = 'Le code postal doit contenir 5 chiffres.';

  // 3. Afficher les erreurs (ou les effacer)
  for (const champ of form.elements) {
    if (!champ.name) continue;
    const zone = document.querySelector(`#err-${champ.name}`);
    const message = erreurs[champ.name];
    champ.setAttribute('aria-invalid', message ? 'true' : 'false');
    if (zone) zone.textContent = message || '';
  }

  // 4. Focus sur le premier champ en erreur
  const premier = Object.keys(erreurs)[0];
  if (premier) {
    form.elements[premier].focus();
    return;                                     // on n'enregistre pas
  }

  // 5. Succès
  enregistrerClient(donnees);
  document.querySelector('#statut').textContent = `Client « ${donnees.nom} » enregistré.`;
  form.reset();
});

function validerLigne(donnees, stockDisponible) {
  const erreurs = {};
  const qte = Number(donnees.quantite);
  if (!donnees.produit) erreurs.produit = 'Choisissez un produit.';
  if (!Number.isInteger(qte) || qte < 1) erreurs.quantite = 'Quantité invalide.';
  else if (qte > stockDisponible) erreurs.quantite = 'Stock insuffisant.';
  return erreurs;
}

subtitle: Sérialiser, mémoriser des préférences, exporter une sauvegarde

§intro
<p>Quand on recharge la page, toutes les variables JavaScript disparaissent. Pour garder une information, le navigateur offre le <strong>LocalStorage</strong> : un petit espace (environ 5 Mo) qui stocke des paires clé/valeur, <strong>uniquement des chaînes</strong>, et qui persiste même après fermeture du navigateur.</p>
<ul>
<li><code>localStorage.setItem('cle', 'valeur')</code> : enregistrer ;</li>
<li><code>localStorage.getItem('cle')</code> : lire (renvoie <code>null</code> si absent) ;</li>
<li><code>localStorage.removeItem('cle')</code> : supprimer.</li>
</ul>
<p>Pour stocker un objet ou un tableau, on le transforme en texte au format <strong>JSON</strong> (JavaScript Object Notation) avec <code>JSON.stringify()</code>, et on le relit avec <code>JSON.parse()</code>. JSON est aussi le format universel d'échange entre applications et des fichiers de sauvegarde.</p>
<p>LocalStorage convient aux <strong>petites données</strong> : thème, préférences, brouillon, progression. Pour des centaines de commandes et des images, on utilise IndexedDB (chapitre suivant).</p>
§example js
const PREFIXE = 'oc.';     // évite les collisions avec d'autres applis du même domaine

// Écrire et lire une valeur simple
localStorage.setItem(PREFIXE + 'theme', 'dark');
const theme = localStorage.getItem(PREFIXE + 'theme') || 'light';   // valeur par défaut

// Objet → JSON → LocalStorage
const preferences = { lignesParPage: 25, triCommandes: 'date-desc', sons: false };
localStorage.setItem(PREFIXE + 'prefs', JSON.stringify(preferences));

// LocalStorage → JSON → objet, avec protection contre un contenu corrompu
function lirePrefs() {
  try {
    return JSON.parse(localStorage.getItem(PREFIXE + 'prefs')) ?? {};
  } catch (erreur) {
    console.warn('Préférences illisibles, valeurs par défaut utilisées.');
    return {};
  }
}
console.log(lirePrefs().lignesParPage);   // 25

// Exporter une sauvegarde JSON téléchargeable
function exporter(donnees) {
  const texte = JSON.stringify({ version: 1, date: new Date().toISOString(), donnees }, null, 2);
  const blob = new Blob([texte], { type: 'application/json' });
  const lien = document.createElement('a');
  lien.href = URL.createObjectURL(blob);
  lien.download = `ondea-sauvegarde-${new Date().toISOString().slice(0, 10)}.json`;
  lien.click();                          // déclenche le téléchargement
  URL.revokeObjectURL(lien.href);        // libère la mémoire
}
§explain
<ul>
<li><code>||</code> fournit une valeur par défaut si <code>getItem</code> renvoie <code>null</code>.</li>
<li><code>??</code> (coalescence) ne remplace que <code>null</code>/<code>undefined</code>, pas <code>0</code> ni <code>''</code>.</li>
<li><code>JSON.parse</code> lève une erreur si le texte n'est pas du JSON valide : on l'entoure de <code>try…catch</code>.</li>
<li><code>JSON.stringify(obj, null, 2)</code> indente le JSON de 2 espaces : lisible par un humain.</li>
<li>JSON ne connaît pas les dates ni les fonctions : une date devient une chaîne ISO (« 2026-11-03T10:00:00.000Z »).</li>
<li>Un <code>Blob</code> est un « fichier en mémoire » ; <code>URL.createObjectURL</code> lui donne une adresse temporaire utilisable dans un lien de téléchargement.</li>
<li>Ne stockez <strong>jamais</strong> de mot de passe ou de donnée sensible en clair dans LocalStorage : tout script de la page peut le lire.</li>
</ul>

function sauver(cle, valeur) {
  localStorage.setItem(PREFIXE + cle, JSON.stringify(valeur));
}
function charger(cle, defaut) {
  const texte = localStorage.getItem(PREFIXE + cle);
  if (texte === null) return defaut;
  try {
    return JSON.parse(texte);
  } catch (e) {
    return defaut;
  }
}

§§chapter js-indexeddb
part: js
title: IndexedDB et gestion des images
subtitle: Une vraie base de données dans le navigateur
duration: 2 h 30
feature: Base locale des commandes et photos (Blob)
§intro
<p><strong>IndexedDB</strong> est une base de données intégrée au navigateur. Contrairement à LocalStorage, elle stocke de <strong>grandes quantités</strong> de données (des centaines de Mo), des <strong>objets</strong> directement (pas besoin de JSON), des <strong>fichiers</strong> (images en <code>Blob</code>), avec des <strong>index</strong> pour chercher vite et des <strong>transactions</strong> pour garantir la cohérence.</p>
<p>Le vocabulaire :</p>
<ul>
<li><strong>Base</strong> (database) : par exemple <code>ondea-commandes</code>, avec un numéro de <strong>version</strong>.</li>
<li><strong>Magasin d'objets</strong> (object store) : l'équivalent d'une table : <code>clients</code>, <code>orders</code>, <code>files</code>.</li>
<li><strong>Clé</strong> (keyPath) : la propriété unique de chaque objet, souvent <code>id</code>.</li>
<li><strong>Index</strong> : permet de chercher par une autre propriété (le statut, le client).</li>
<li><strong>Transaction</strong> : un groupe d'opérations qui réussissent toutes ou échouent toutes.</li>
</ul>
<p>L'API est <strong>asynchrone</strong> et basée sur des événements (<code>onsuccess</code>, <code>onerror</code>). On l'enveloppe dans des <strong>promesses</strong> pour écrire du code clair avec <code>async/await</code> (chapitre suivant).</p>
§example js
// 1. Ouvrir (ou créer) la base, version 1
function ouvrirBase() {
  return new Promise((resolve, reject) => {
    const requete = indexedDB.open('ondea-cours', 1);

    // Appelé seulement à la création ou quand la version augmente
    requete.onupgradeneeded = () => {
      const db = requete.result;
      const clients = db.createObjectStore('clients', { keyPath: 'id' });
      clients.createIndex('ville', 'ville');                 // index de recherche
      db.createObjectStore('files', { keyPath: 'id' });      // pour les images
    };
    requete.onsuccess = () => resolve(requete.result);
    requete.onerror = () => reject(requete.error);
  });
}

// 2. Petite fonction utilitaire : transformer une requête en promesse
const promesse = (req) => new Promise((ok, ko) => { req.onsuccess = () => ok(req.result); req.onerror = () => ko(req.error); });

}

const promesse = (r) => new Promise((ok, ko) => { r.onsuccess = () => ok(r.result); r.onerror = () => ko(r.error); });
const fin = (tx) => new Promise((ok, ko) => { tx.oncomplete = ok; tx.onerror = () => ko(tx.error); tx.onabort = () => ko(tx.error); });
function ouvrir() {
  const r = indexedDB.open('ondea-equipe', 1);
  r.onupgradeneeded = () => {
    r.result.createObjectStore('users', { keyPath: 'id' });
    r.result.createObjectStore('files', { keyPath: 'id' }).createIndex('owner', ['ownerType', 'ownerId']);
  };
  return promesse(r);
}
async function creerUtilisateur({ nom, role }, photo) {
  if (photo && !photo.type.startsWith('image/')) throw new Error('Le fichier doit être une image.');
  if (photo && photo.size > 2 * 1024 * 1024) throw new Error('Image trop lourde (2 Mo maximum).');
  const db = await ouvrir();
  const id = crypto.randomUUID();
  const tx = db.transaction(['users', 'files'], 'readwrite');
  tx.objectStore('users').put({ id, nom, role });
  if (photo) tx.objectStore('files').put({ id: 'photo-' + id, ownerType: 'user', ownerId: id, blob: photo });
  await fin(tx);
  return id;
}
async function supprimerUtilisateur(id) {
  const db = await ouvrir();
  const tx = db.transaction(['users', 'files'], 'readwrite');
  tx.objectStore('users').delete(id);
  tx.objectStore('files').delete('photo-' + id);
  await fin(tx);
}
async function listerAvecPhotos() {
  const db = await ouvrir();
  const users = await promesse(db.transaction('users').objectStore('users').getAll());
  const files = db.transaction('files').objectStore('files');
  return Promise.all(users.map(async (u) => {
    const f = await promesse(files.get('photo-' + u.id));
    return { ...u, photoUrl: f ? URL.createObjectURL(f.blob) : null };
  }));

§intro
<p>Certaines opérations prennent du temps : ouvrir la base, lire un fichier, attendre 30 secondes. Le JavaScript ne s'arrête pas pour attendre : il est <strong>asynchrone</strong>. Il continue et sera prévenu plus tard.</p>
<ul>
<li>Une <strong>promesse</strong> (<code>Promise</code>) représente un résultat futur : en attente, puis <em>tenue</em> (résultat) ou <em>rompue</em> (erreur).</li>
<li><code>async</code> devant une fonction permet d'utiliser <code>await</code> à l'intérieur ; <code>await</code> « attend » la promesse et donne son résultat, comme si le code était séquentiel.</li>
<li><code>try { … } catch (erreur) { … }</code> attrape les erreurs pour afficher un message au lieu de planter.</li>
<li><code>Promise.all([...])</code> lance plusieurs opérations en parallèle.</li>
</ul>
<p><strong>Organisation :</strong> une application de 10 000 lignes doit être découpée en fichiers par responsabilité (utilitaires, stockage, interface, un fichier par module métier). En <code>file://</code>, les modules ES (<code>import</code>) sont bloqués : on charge des scripts classiques dans l'ordre avec <code>defer</code>, et chaque fichier s'enregistre dans <strong>un seul</strong> objet global (un <strong>espace de noms</strong>) pour ne pas polluer la page.</p>
§example js
// ---------- utils.js : chargé en premier ----------
// IIFE : fonction exécutée immédiatement, ses variables restent privées
(function (global) {
  'use strict';                                  // mode strict : plus d'erreurs détectées
  const OC = global.OC = global.OC || {};        // espace de noms unique

  const pause = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
  OC.utils = { pause };                          // on n'expose que l'utile
})(window);

// ---------- database.js : utilise OC.utils ----------
(function (OC) {
  'use strict';
  async function ouvrir() {
    await OC.utils.pause(300);                   // simule une ouverture lente
    return { nom: 'ondea-commandes' };
  }
  OC.db = { ouvrir };
})(window.OC);

// ---------- app.js : chargé en dernier, démarre tout ----------
(function (OC) {
  'use strict';
  async function demarrer() {
    try {
      console.log('Démarrage…');
      const db = await OC.db.ouvrir();           // attend sans bloquer la page
      const [prefs, notifs] = await Promise.all([ // en parallèle
        chargerPreferences(), compterNotifications()
      ]);
      console.log(`Base ${db.nom} prête, ${notifs} notifications`, prefs);
    } catch (erreur) {
      console.error(erreur);
      afficherErreur("L'application n'a pas pu démarrer. Rechargez la page.");
    } finally {
      document.body.classList.remove('is-loading'); // toujours exécuté
    }
  }
  document.addEventListener('DOMContentLoaded', demarrer);
})(window.OC);
§explain
<ul>
<li>L'<strong>IIFE</strong> <code>(function () { … })()</code> crée une portée privée : les variables internes ne deviennent pas globales.</li>
<li><code>global.OC = global.OC || {}</code> : on réutilise l'objet s'il existe, sinon on le crée. Tous les fichiers ajoutent leur partie : <code>OC.utils</code>, <code>OC.db</code>…</li>
<li>L'<strong>ordre des balises script</strong> compte : <code>database.js</code> utilise <code>OC.utils</code>, il doit donc être chargé après <code>utils.js</code>.</li>
<li><code>await</code> ne fonctionne que dans une fonction <code>async</code> (ou au niveau supérieur d'un module ES).</li>
<li><code>finally</code> s'exécute dans tous les cas, succès ou erreur : idéal pour retirer un indicateur de chargement.</li>
<li>Une fonction <code>async</code> renvoie toujours une promesse.</li>
<li><code>window.addEventListener('unhandledrejection', …)</code> attrape les erreurs de promesses oubliées : un filet de sécurité global.</li>
</ul>

Les scripts sont donc classiques (<code>defer</code>), chargés dans l'ordre, et chacun s'enregistre dans un <strong>unique</strong> espace de noms ». <code>utils.js</code> crée <code>window.OC</code> et des classes d'erreurs (<code>AppError</code>, <code>PermissionError</code>, <code>ValidationError</code>) ; <code>app.js</code> assure « l'amorçage, la gestion centralisée des erreurs, les raccourcis et la synchronisation entre onglets ».</p>
