§§chapter css-selecteurs
part: css
title: Sélecteurs, cascade et spécificité
subtitle: Cibler exactement le bon élément
duration: 1 h 30
feature: Boutons et badges de statut
§intro
<p>Le <strong>CSS</strong> (Cascading Style Sheets) décrit l'apparence. Une <strong>règle</strong> CSS a deux parties : un <strong>sélecteur</strong> (qui ?) et des <strong>déclarations</strong> (quoi ?) entre accolades, sous la forme <code>propriété: valeur;</code>.</p>
<p>Les sélecteurs essentiels :</p>
<ul>
<li><code>p</code> : tous les paragraphes (sélecteur d'<strong>élément</strong>).</li>
<li><code>.btn</code> : tous les éléments ayant <code>class="btn"</code> (<strong>classe</strong>, le plus utilisé).</li>
<li><code>#contenu</code> : l'élément <code>id="contenu"</code> (unique, à éviter pour le style).</li>
<li><code>[data-theme="dark"]</code> : sélecteur d'<strong>attribut</strong>.</li>
<li><code>.nav a</code> : les liens <em>à l'intérieur</em> de <code>.nav</code> (descendant).</li>
<li><code>.btn:hover</code>, <code>:focus-visible</code>, <code>li:nth-child(2)</code> : <strong>pseudo-classes</strong> (un état ou une position).</li>
</ul>
<p>Quand deux règles se contredisent, le navigateur applique la <strong>cascade</strong> : la règle la plus <strong>spécifique</strong> gagne (id &gt; classe &gt; élément) ; à égalité, la <strong>dernière</strong> écrite gagne.</p>
§example css
/* Sélecteur de classe : la base de tous les boutons */
.btn {
  padding: .6rem 1.1rem;          /* espace intérieur */
  border-radius: 10px;            /* coins arrondis */
  border: 1px solid transparent;
  font-weight: 700;
  cursor: pointer;                /* main au survol */
}

/* Variante : deux classes sur le même élément class="btn btn-primary" */
.btn-primary { background: #171a26; color: #fdf8ea; }

/* Pseudo-classe : état survolé */
.btn-primary:hover { background: #262a3b; }

/* Focus clavier visible : NE JAMAIS le supprimer */
.btn:focus-visible { outline: 3px solid #1d4ed8; outline-offset: 2px; }

/* Sélecteur d'attribut : badge selon le statut */
.badge[data-status="livree"]  { background: #dcf3e4; color: #0b4a26; }
.badge[data-status="annulee"] { background: #fbe0de; color: #7a1410; }

/* Descendant : liens du menu seulement */
.sidebar nav a { text-decoration: none; }
§explain
<ul>
<li>Une classe est réutilisable : on compose <code>class="btn btn-primary"</code> plutôt que de tout réécrire.</li>
<li><code>:hover</code> = survol souris ; <code>:focus-visible</code> = focus clavier. Supprimer le contour de focus est une faute d'accessibilité grave.</li>
<li><code>[data-status="livree"]</code> cible un attribut : pratique quand le JS change l'état d'un élément.</li>
<li>Spécificité : <code>#id</code> vaut (1,0,0), <code>.classe</code>/<code>[attr]</code>/<code>:hover</code> valent (0,1,0), <code>p</code> vaut (0,0,1). On les additionne.</li>
<li><code>!important</code> écrase tout : à réserver aux cas exceptionnels, il rend le code difficile à maintenir.</li>
</ul>

§intro
<p>Une couleur s'écrit de plusieurs façons : <code>#c9a14a</code> (hexadécimal : rouge, vert, bleu de 00 à ff), <code>rgb(201 161 74)</code>, avec transparence <code>rgb(201 161 74 / 45%)</code>, ou <code>hsl()</code> (teinte, saturation, luminosité).</p>
<p>Le <strong>contraste</strong> entre le texte et le fond se mesure par un ratio : 4,5:1 minimum (niveau AA), <strong>7:1</strong> pour le niveau AAA visé par Ondea. Un gris clair sur blanc paraît élégant mais devient illisible pour beaucoup de gens.</p>
<p>Pour la typographie : <code>font-family</code> (avec des polices de secours), <code>font-size</code> en <code>rem</code> (relatif à la taille choisie par l'utilisateur, 1rem = 16px par défaut), <code>line-height</code> autour de 1,5 pour le texte courant, et une largeur de ligne limitée (environ 70 caractères : <code>max-width: 70ch</code>).</p>
<p>On peut embarquer une police avec <code>@font-face</code> et un fichier <code>.woff2</code> : l'application fonctionne alors hors ligne.</p>
§example css
/* Embarquer une police locale (fonctionne sans Internet) */
@font-face {
  font-family: "Atkinson Hyperlegible";
  src: url("../assets/fonts/atkinson-hyperlegible-400.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;      /* affiche une police de secours en attendant */
}

body {
  /* Police principale puis polices de secours */
  font-family: "Atkinson Hyperlegible", system-ui, sans-serif;
  font-size: 1rem;         /* respecte le réglage du navigateur */
  line-height: 1.6;        /* interligne confortable */
  color: #14161f;          /* quasi-noir sur fond ivoire : 16:1 */
  background: #f4f1ea;
}

h1, h2 {
  font-family: "Playfair Display", Georgia, serif;
  line-height: 1.2;
  color: #0f111a;
}

/* Taille fluide : jamais moins de 1.8rem, jamais plus de 3rem */
h1 { font-size: clamp(1.8rem, 1.2rem + 2.5vw, 3rem); }

.texte-or { color: #614608; }   /* or foncé lisible (≥ 7:1 sur blanc) */
.prose    { max-width: 70ch; }  /* lignes pas trop longues */
§explain
<ul>
<li><code>font-display: swap</code> évite un texte invisible pendant le chargement de la police.</li>
<li>Le doré vif <code>#c9a14a</code> ne contraste pas assez avec le blanc pour du texte : Ondea l'utilise en décor (bordures, halos) et réserve <code>#614608</code> pour le texte doré.</li>
<li><code>clamp(min, idéal, max)</code> crée une taille qui grandit avec l'écran (<code>vw</code> = 1 % de la largeur de la fenêtre) sans dépasser les bornes.</li>
<li><code>ch</code> = largeur du caractère « 0 » : <code>70ch</code> ≈ 70 caractères par ligne.</li>
<li>Préférez <code>rem</code> à <code>px</code> pour les tailles de texte : l'utilisateur qui agrandit la police par défaut sera respecté.</li>
</ul>

§§chapter css-box-model
part: css
title: Le modèle de boîte
subtitle: content, padding, border, margin et box-sizing
duration: 1 h
feature: Les cartes du tableau de bord
§intro
<p>Pour le navigateur, <strong>chaque élément est une boîte rectangulaire</strong> composée de quatre couches, de l'intérieur vers l'extérieur :</p>
<ol>
<li><strong>content</strong> : le contenu (texte, image), dimensionné par <code>width</code>/<code>height</code> ;</li>
<li><strong>padding</strong> : l'espace intérieur, qui prend la couleur de fond ;</li>
<li><strong>border</strong> : la bordure ;</li>
<li><strong>margin</strong> : l'espace extérieur, transparent, qui éloigne les autres boîtes.</li>
</ol>
<p>Piège classique : par défaut, <code>width: 300px</code> ne compte que le contenu ; le padding et la bordure s'ajoutent. Avec <code>box-sizing: border-box</code>, la largeur inclut padding et bordure : beaucoup plus intuitif. Presque tous les projets professionnels commencent par cette règle.</p>
<p>Il existe aussi deux grands types d'affichage : <code>block</code> (prend toute la largeur, passe à la ligne : div, p, h1) et <code>inline</code> (dans le flux du texte : span, a, strong).</p>
§example css
/* Règle de base de tout projet : la largeur inclut padding + bordure */
*, *::before, *::after { box-sizing: border-box; }

.card {
  width: 100%;
  max-width: 320px;              /* jamais plus large que 320px */
  padding: 1.25rem;              /* espace intérieur sur les 4 côtés */
  border: 1px solid #e2dbcc;     /* épaisseur, style, couleur */
  border-radius: 14px;
  margin-bottom: 1rem;           /* espace sous la carte */
  background: #ffffff;
  box-shadow: 0 10px 30px rgb(23 26 38 / 10%);  /* profondeur */
}

/* Raccourcis : haut droite bas gauche (sens des aiguilles d'une montre) */
.kpi-valeur { margin: 0 0 .25rem 0; }
.kpi-label  { padding: .25rem .5rem; }  /* vertical | horizontal */

/* Centrer un bloc horizontalement */
.conteneur { max-width: 1200px; margin-inline: auto; }
§explain
<ul>
<li>Le sélecteur universel <code>*</code> applique <code>border-box</code> à tous les éléments et pseudo-éléments.</li>
<li><code>max-width</code> laisse la carte rétrécir sur mobile mais l'empêche de trop s'étaler sur grand écran.</li>
<li>Valeurs raccourcies : 1 valeur = 4 côtés ; 2 valeurs = vertical puis horizontal ; 4 valeurs = haut, droite, bas, gauche.</li>
<li><code>margin-inline: auto</code> répartit l'espace restant à gauche et à droite : le bloc est centré.</li>
<li>Les marges verticales de deux blocs voisins <strong>fusionnent</strong> (la plus grande l'emporte) : c'est le « margin collapsing ».</li>
<li>Dans l'inspecteur du navigateur, l'onglet « Calculé » dessine le modèle de boîte de l'élément sélectionné.</li>
</ul>

§§chapter css-flexbox
part: css
title: Flexbox
subtitle: Aligner des éléments sur une ligne ou une colonne
duration: 1 h 30
feature: Barre supérieure et barres d'actions
§intro
<p><strong>Flexbox</strong> sert à aligner des éléments <strong>sur un seul axe</strong> : une ligne (barre d'outils, menu horizontal) ou une colonne. On l'active sur le <strong>parent</strong> avec <code>display: flex</code> ; ses enfants directs deviennent des « éléments flexibles ».</p>
<p>Les propriétés du parent à connaître :</p>
<ul>
<li><code>flex-direction</code> : <code>row</code> (ligne, défaut) ou <code>column</code>.</li>
<li><code>justify-content</code> : répartition sur l'axe principal (<code>flex-start</code>, <code>center</code>, <code>space-between</code>…).</li>
<li><code>align-items</code> : alignement sur l'axe secondaire (<code>center</code> pour centrer verticalement).</li>
<li><code>gap</code> : espace entre les enfants.</li>
<li><code>flex-wrap: wrap</code> : passage à la ligne si la place manque.</li>
</ul>
<p>Côté enfant, <code>flex: 1</code> signifie « prends toute la place restante ».</p>
§example css
/* Barre supérieure : titre à gauche, actions à droite */
.topbar {
  display: flex;                    /* active Flexbox */
  align-items: center;              /* centre verticalement */
  justify-content: space-between;   /* écarte les extrémités */
  gap: 1rem;                        /* espace entre enfants */
  padding: .75rem 1.25rem;
  min-height: 68px;
}

/* La recherche prend toute la place disponible */
.topbar .recherche { flex: 1; max-width: 480px; }

/* Groupe de boutons */
.actions {
  display: flex;
  gap: .5rem;
  flex-wrap: wrap;                  /* passe à la ligne sur mobile */
}

/* Centrer parfaitement un élément (écran vide, chargement) */
.centre {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 60vh;
}
§explain
<ul>
<li><code>display: flex</code> agit sur les <strong>enfants directs</strong> uniquement, pas sur les petits-enfants.</li>
<li>Axe principal = sens de <code>flex-direction</code>. Si on passe en <code>column</code>, <code>justify-content</code> agit verticalement.</li>
<li><code>space-between</code> colle le premier élément à gauche, le dernier à droite, et répartit le reste.</li>
<li><code>gap</code> remplace les marges entre éléments : plus de problème de marge en trop sur le dernier.</li>
<li><code>flex: 1</code> est un raccourci de <code>flex-grow: 1; flex-shrink: 1; flex-basis: 0</code>.</li>
<li><code>margin-left: auto</code> sur un enfant le pousse tout à droite.</li>
</ul>

§§chapter css-grid
part: css
title: CSS Grid
subtitle: Mises en page en deux dimensions
duration: 1 h 30
feature: Structure de l'application et grille d'indicateurs
§intro
<p><strong>CSS Grid</strong> organise des éléments en <strong>lignes ET colonnes</strong> à la fois. C'est l'outil idéal pour la structure générale d'une application (barre latérale + contenu) et pour les grilles de cartes.</p>
<ul>
<li><code>display: grid</code> active la grille sur le parent.</li>
<li><code>grid-template-columns: 268px 1fr</code> : une colonne fixe de 268px puis une colonne qui prend le reste. L'unité <code>fr</code> signifie « fraction de l'espace libre ».</li>
<li><code>repeat(3, 1fr)</code> : trois colonnes égales.</li>
<li><code>repeat(auto-fit, minmax(220px, 1fr))</code> : « autant de colonnes de 220px minimum qu'il en tient ». Responsive sans aucune media query !</li>
<li><code>grid-template-areas</code> : on dessine la mise en page avec des noms de zones.</li>
</ul>
<p>Flexbox ou Grid ? Flexbox pour une ligne de contenus, Grid pour une mise en page à deux dimensions. Les deux se combinent très bien.</p>
§example css
/* Structure de l'application dessinée avec des zones nommées */
.app {
  display: grid;
  grid-template-columns: 268px 1fr;      /* barre latérale | contenu */
  grid-template-rows: 68px 1fr;          /* barre supérieure | écran */
  grid-template-areas:
    "sidebar topbar"
    "sidebar main";
  min-height: 100vh;
}
.app > aside  { grid-area: sidebar; }
.app > header { grid-area: topbar; }
.app > main   { grid-area: main; }

/* Grille d'indicateurs : responsive automatiquement */
.kpis {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

/* Une carte qui occupe 2 colonnes */
.graphique-ca { grid-column: span 2; }
§explain
<ul>
<li><code>grid-template-areas</code> se lit comme un dessin : chaque chaîne est une ligne, chaque mot une cellule. Un nom répété fusionne les cellules.</li>
<li><code>grid-area</code> place un enfant dans la zone portant ce nom.</li>
<li><code>minmax(220px, 1fr)</code> : jamais moins de 220px, et partage de l'espace en plus.</li>
<li><code>auto-fit</code> crée autant de colonnes que possible et étire les cartes pour remplir la ligne.</li>
<li><code>grid-column: span 2</code> étend une carte sur deux colonnes.</li>
<li>L'inspecteur de Chrome/Firefox a un badge « grid » qui dessine les lignes de la grille : utilisez-le !</li>
</ul>

§§chapter css-responsive
part: css
title: Responsive design
subtitle: Mobile first, media queries, images et tableaux adaptatifs
duration: 1 h 30
feature: Ondea sur tablette et smartphone (magasinier en entrepôt)
§intro
<p>Le magasinier prépare les commandes dans l'entrepôt, tablette ou téléphone à la main : l'application doit être aussi confortable sur un écran de 360px que sur un écran de 1920px. C'est le <strong>responsive design</strong>.</p>
<p>La démarche <strong>mobile first</strong> : on écrit d'abord le CSS pour le petit écran (une colonne, gros boutons), puis on ajoute des règles pour les écrans plus larges avec des <strong>media queries</strong> :</p>
<p><code>@media (min-width: 900px) { ... }</code> = « à partir de 900px de large, applique aussi ces règles ».</p>
<p>Autres outils : unités relatives (<code>%</code>, <code>rem</code>, <code>vw</code>), <code>max-width: 100%</code> sur les images, zones tactiles d'au moins 44×44px, et les <strong>préférences utilisateur</strong> : <code>prefers-color-scheme</code> (thème), <code>prefers-reduced-motion</code> (animations).</p>
§example css
/* 1. Mobile d'abord : une seule colonne, menu caché */
.app { display: block; }
.sidebar {
  position: fixed; inset: 0 auto 0 0;
  width: 268px;
  transform: translateX(-100%);       /* hors de l'écran */
  transition: transform .24s;
}
.sidebar.is-open { transform: none; } /* ouvert par le bouton menu */

/* Zones tactiles confortables */
.btn { min-height: 44px; padding-inline: 1rem; }

/* Images et tableaux jamais plus larges que l'écran */
img { max-width: 100%; height: auto; }
.table-wrap { overflow-x: auto; }

/* 2. Tablette paysage et ordinateur : barre latérale fixe */
@media (min-width: 900px) {
  .app { display: grid; grid-template-columns: 268px 1fr; }
  .sidebar { position: sticky; top: 0; height: 100vh; transform: none; }
  .btn-menu { display: none; }        /* bouton menu inutile */
}

/* 3. Grand écran : on limite la largeur du contenu */
@media (min-width: 1400px) {
  main { max-width: 1280px; margin-inline: auto; }
}
§explain
<ul>
<li>Sans <code>&lt;meta name="viewport"&gt;</code> dans le HTML, les media queries ne fonctionnent pas correctement sur mobile.</li>
<li><code>transform: translateX(-100%)</code> décale le menu de sa propre largeur vers la gauche : il est caché, prêt à glisser.</li>
<li><code>position: sticky; top: 0</code> : l'élément défile normalement puis reste collé en haut.</li>

§§chapter css-variables-themes
part: css
title: Variables CSS et thèmes clair / sombre
subtitle: Custom properties, data-theme et prefers-color-scheme
duration: 1 h 30
feature: Mode clair / mode sombre mémorisé
§intro
<p>Une <strong>variable CSS</strong> (custom property) commence par deux tirets : <code>--gold: #c9a14a;</code>. On la lit avec <code>var(--gold)</code>. On les déclare en général sur <code>:root</code> (la racine du document) pour qu'elles soient disponibles partout.</p>
<p>Leur super-pouvoir : on peut les <strong>redéfinir</strong> dans un autre sélecteur. Pour créer un thème sombre, il suffit de redéfinir les mêmes variables dans <code>[data-theme="dark"]</code> : tous les composants qui utilisent <code>var(--bg)</code> changent d'un coup.</p>
<p>On nomme les variables par leur <strong>rôle</strong> (<code>--bg</code>, <code>--text</code>, <code>--surface</code>, <code>--border</code>) et non par leur couleur (<code>--blanc</code>) : en thème sombre, <code>--bg</code> n'est plus blanc !</p>
§example css
/* Thème clair : valeurs par défaut sur la racine */
:root {
  --bg: #f4f1ea;          /* fond de page ivoire */
  --surface: #ffffff;     /* fond des cartes */
  --text: #14161f;        /* texte principal */
  --border: #e2dbcc;
  --gold: #c9a14a;        /* décor */
  --gold-text: #614608;   /* texte doré lisible */
  --radius: 14px;
  color-scheme: light;    /* barres de défilement, champs natifs clairs */
}

/* Thème sombre : on redéfinit SEULEMENT les valeurs */
[data-theme="dark"] {
  --bg: #0b0c12;          /* obsidienne */
  --surface: #151824;
  --text: #f2eee4;
  --border: #2c3142;
  --gold-text: #e2c27a;
  color-scheme: dark;
}

/* Les composants n'utilisent que des variables */
body  { background: var(--bg); color: var(--text); }
.card {
  background: var(--surface);
  border: 1px solid var(--border);
  border-radius: var(--radius);
}
.lien-or { color: var(--gold-text); }

/* Valeur de secours si la variable n'existe pas */
.badge { background: var(--badge-bg, #ebe7de); }
§explain
<ul>
<li><code>:root</code> = l'élément <code>&lt;html&gt;</code>, avec une spécificité de classe.</li>
<li>Le JavaScript change le thème en une ligne : <code>document.documentElement.dataset.theme = 'dark'</code>.</li>
<li><code>color-scheme</code> indique au navigateur d'adapter ses éléments natifs (cases, barres de défilement, calendrier).</li>
<li>Les variables héritent : définies sur un parent, elles valent pour tous ses descendants, et on peut les surcharger localement (<code>.kpi--ca { --accent: gold }</code>).</li>
<li><code>var(--x, secours)</code> fournit une valeur par défaut.</li>
<li>Pour respecter le réglage du système au premier lancement : <code>matchMedia('(prefers-color-scheme: dark)')</code> en JS, ou une media query en CSS.</li>
</ul>

§§chapter css-animations
part: css
title: Transitions, animations et effets visuels
subtitle: transition, transform, @keyframes, ombres, dégradés et reduced motion
duration: 2 h
feature: Micro-interactions et effets premium
§intro
<p>Une bonne animation <strong>explique</strong> ce qui se passe : un panneau qui glisse indique d'où il vient, un bouton qui s'enfonce confirme le clic. Elle doit être <strong>courte</strong> (150 à 300 ms) et ne jamais gêner.</p>
<ul>
<li><code>transition</code> : anime le passage d'un état à un autre (au survol, à l'ajout d'une classe).</li>
<li><code>transform</code> : déplace (<code>translate</code>), agrandit (<code>scale</code>) ou tourne (<code>rotate</code>) sans perturber la mise en page. Avec <code>opacity</code>, ce sont les propriétés les plus fluides à animer.</li>
<li><code>@keyframes</code> + <code>animation</code> : une animation en plusieurs étapes, éventuellement en boucle.</li>
<li>Effets : <code>box-shadow</code> (ombres et halos), <code>linear-gradient</code> (dégradés), <code>backdrop-filter: blur()</code> (verre dépoli).</li>
</ul>
<p><strong>Obligatoire :</strong> certaines personnes (troubles vestibulaires, migraines) sont malades devant le mouvement. La media query <code>prefers-reduced-motion: reduce</code> permet de couper les animations quand l'utilisateur l'a demandé dans son système.</p>
§example css
/* Micro-interaction : le bouton se soulève au survol */
.btn {
  transition: transform .14s ease-out, box-shadow .14s ease-out;
}
.btn:hover  { transform: translateY(-2px); box-shadow: 0 8px 20px rgb(201 161 74 / 35%); }
.btn:active { transform: translateY(0) scale(.98); }   /* enfoncé au clic */

/* Apparition d'une carte : de bas en haut avec fondu */
@keyframes apparition {
  from { opacity: 0; transform: translateY(16px); }
  to   { opacity: 1; transform: none; }
}
.card { animation: apparition .48s cubic-bezier(.22, 1, .36, 1) both; }

/* Halo doré autour d'une notification non lue */
@keyframes pulse {
  0%, 100% { box-shadow: 0 0 0 0 rgb(201 161 74 / 45%); }
  50%      { box-shadow: 0 0 0 8px rgb(201 161 74 / 0%); }
}
.notif-non-lue { animation: pulse 2s infinite; }

/* Titre doré avec dégradé dans le texte */
.titre-or {
  background: linear-gradient(90deg, #8a6a1f, #e7c873, #8a6a1f);
  -webkit-background-clip: text; background-clip: text;
  color: transparent;
}

/* RESPECT DES PRÉFÉRENCES : on coupe le mouvement */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
§explain
<ul>
<li><code>transition</code> se place sur l'état <strong>de départ</strong> : l'animation joue dans les deux sens (survol et sortie).</li>
<li>On liste les propriétés animées plutôt que <code>transition: all</code>, plus coûteux et imprévisible.</li>
<li><code>cubic-bezier(.22, 1, .36, 1)</code> est une courbe « ease-out » marquée : départ rapide, arrivée douce, très cinématographique.</li>
<li><code>both</code> (fill-mode) garde l'état initial avant le départ et l'état final après la fin.</li>
<li><code>background-clip: text</code> découpe le fond selon les lettres : le dégradé apparaît dans le texte. Gardez un contraste suffisant !</li>
<li>Dans la règle <code>prefers-reduced-motion</code>, <code>!important</code> est justifié : elle doit l'emporter sur tout.</li>
</ul>

§quiz
? Quelles propriétés sont les plus fluides à animer ?
- width et height
+ transform et opacity
- margin et padding
- top et left
= Elles ne déclenchent pas de recalcul de la mise en page.
? Où écrire la propriété transition pour un effet au survol ?
+ Sur l'état normal de l'élément
- Uniquement dans :hover
- Dans @keyframes
- Sur body
= Ainsi l'effet joue à l'entrée et à la sortie du survol.
? Que permet @media (prefers-reduced-motion: reduce) ?
- Accélérer les animations
+ Réduire ou supprimer le mouvement pour les personnes qui l'ont demandé
- Animer sur mobile
- Économiser la batterie automatiquement
= Critère WCAG 2.3.3 (AAA) : animations déclenchées par une interaction.
? Quelle durée pour une micro-interaction ?
- 2 à 3 secondes
+ Environ 150 à 300 ms
- 1 ms
- 10 secondes
= Assez pour être perçue, assez court pour ne pas ralentir.
? Que fait animation-fill-mode: both ?
- Joue l'animation deux fois
+ Applique l'état de départ avant l'animation et garde l'état final après
- Joue dans les deux sens

= Évite un « flash » de l'état final avant le départ.
